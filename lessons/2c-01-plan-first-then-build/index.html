Module 2 · Everyone’s a builder · Lesson 2C.1

Plan first, then build

Ask for the plan before the work. Fixing a plan takes an eraser. Fixing a build takes a sledgehammer.

How it works

1

In the plan, a mistake costs an eraser.

Before anything is built, changing your mind means rewording a sentence.

How it works

2

While building, it costs a hammer.

Once files are written, a wrong idea has spread into many places. Fixing it means undoing work.

How it works

3

After it’s live, it costs a wrecking ball.

Once people use it, a mistake can mean lost data, confused users and a lot of rebuilding.

Good to know

Plan mode and auto mode

Many AI coding tools have a plan mode, where the AI writes a plan and changes nothing until you approve it. Auto mode (the name varies by tool) is the opposite: it builds and acts without stopping to ask each time.

What experience teaches

Most bad builds are good builds of a bad plan nobody read.

The AI did exactly what the plan said; the plan was wrong. Reading a plan takes five minutes. Rebuilding can take days.

So read the plan like a contractor’s quote. Does it solve the problem you actually have? Does it touch anything it shouldn’t? Does it say how it will check its own work? Save auto mode for jobs where the plan is clear and mistakes are cheap to undo.

Try this · 1 of 2

Ask for the plan, not the thing

I want a simple page where my family can sign up for chores each week. Don’t build anything yet. Write a short plan: what the page will do, what it won’t do, and how we’ll test it.

You’ll see a plan you can read in two minutes, and probably something you’d change.

Try this · 2 of 2

Poke holes in it

What could go wrong with this plan? List the three biggest risks and how to avoid each one.

You’ll see problems showing up on paper, where they’re cheap.

Why: every problem you catch here costs an eraser instead of a sledgehammer.

The catch

A plan can’t catch everything. Some problems only show up when you try the real thing.

And a plan you skim is no better than no plan. The value is in reading it, and saying no to the parts you don’t want.

Remember

Most bad builds are good builds of a bad plan nobody read.
